# 01 — Basics

## Overview
This exercise walks through the basics of Git: creating a branch, adding a file, and committing changes.

## Your Task
1. Fork or copy this sandbox to your own account.
2. Create a branch off `main`.
3. Add this basics exercise file to your branch.

## Tip
Try running `git status`, `git add`, and `git commit` against your own offline clone — it's the same workflow you'll use everywhere.
